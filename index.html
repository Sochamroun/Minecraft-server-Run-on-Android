🌿Minecraft Server Run on Android

An open-source toolkit for running Minecraft Java Servers on Android with Termux. Simplifies installation, configuration, optimization, plugins, and public connectivity via Playit.gg.

🟢 Open Source📱 Android🖥️ Termux🎮 Java Edition🌐 Playit.gg
⭐ View on GitHub Get Started

📖 Overview

Run a full Minecraft Java server directly from your Android phone — no PC required.

📱 Requirements

An Android device with Termux installed.
No root required.

🎮 Multiple Server Types

Paper, Vanilla, and Leaf server scripts are supported.

⚡ Optimization

Mobile-friendly settings to help performance on phone hardware.

🌐 Public Access

Share your server with friends using a Playit.gg tunnel.

🤖 Mineflayer Bot

Set up a bot to join and help keep your world active.

🧩 Plugin Support

Install supported Paper plugins with simple terminal commands.
