## How to use Termux 
| Command line | Description |
|--------------|-------------|
| cd | select folder 📁 |
| ls | show All folder and file |
| nano |Edit file script |
| mkdir |create folder |
| cp | copy file rename |
| du -sh * | show size file= MB |
| ifconfig | show ip |
