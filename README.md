## Change OpenJDK Runtime Environment Java 21 25
- Java 21 Runtime 
```bash
export JAVA_HOME=$PREFIX/lib/jvm/java-21-openjdk
```
- Java 25 Runtime
```bash
export JAVA_HOME=$PREFIX/lib/jvm/java-25-openjdk
```
- Export Java Path
```bash
export PATH=$JAVA_HOME/bin:$PATH
```
- Check Java Runtime
```bash
java -version
```
